# 资产与品牌政策

> 本项目是给 agent 改造的启动器模板，不是官方客户端。
> 本文件不是法律意见；公开前请按所在司法辖区确认。

## 1. 分发边界

- **当前仓库决定（2026-10-26）**：官方图标/字标已按用户要求纳入仓库；它们不属于 MIT 代码许可，风险由发布者承担。
- **推荐边界**：官方图标/字标只放本地 `assets/official/`，公开仓库只保留占位图；若坚持入库，必须保留 `THIRD-PARTY-NOTICES.md`，且不能把整套仓库称为纯 MIT/CC0。
- **用户本地**：官方资产与社区参考图放在 git-ignored 目录，由用户自行承担授权责任。

## 2. 占位图标

- 资产：`assets/placeholders/generated/*.png`
- 许可：L/C 为 CC0-1.0；DSH 头像为社区参考图编辑，标注 CC BY-SA 4.0，参考图不入库。
- 性质：占位，不声称官方；与任何官方组织无关联。
- 生成方式：Qwen-Image-2.1-Turbo（本地 sd.cpp）；提示词与设计 brief 一并保留，作为原创过程证据。

## 3. “重绘”不等于“去版权”

按原图思路/配色重画，仍可能构成衍生作品或商标侵权。  
如果目标是与官方视觉高度一致，正确路径是取得品牌方书面许可，而不是靠“自己重画”。

## 4. 演示视频

公开视频默认使用占位图标。若必须出现官方图标：

- 仅用于指示被集成的软件，不用于项目 logo/封面/频道品牌；
- 不修改官方图形，不暗示官方合作/背书；
- 遵守对应品牌指南；
- 注意 llama.cpp 品牌含 CC BY-NC 的 NonCommercial 限制；
- 商业推广/变现视频风险更高，先取得许可；
- 加免责声明：`Not affiliated with or endorsed by ...`。

## 5. 用户替换

用户/agent 替换官方图标时：

1. 只放在本地 `assets/official/<id>/`；
2. manifest 的 `icon.source` 改为 `official`；
3. 填写 `license` / `credit`；
4. 不把该目录提交到公开仓库；
5. 不把官方图标作为本项目品牌使用。

## 6. 当前仓库状态（已按用户决定接受风险）

当前页面：

- llama / ComfyUI：**官方图标与完整字标**；
- DSH：**鲸鱼娘头像**（社区参考图编辑，CC BY-SA 4.0，非官方）；
- 官方图标与官方字标已经纳入仓库，不再只放本地。

这意味着仓库**不是纯 CC0/MIT 资产包**：品牌图标的版权/商标风险由发布者承担。若以后要回到“干净开源分发”，应把官方资产移到本地 `assets/official/`、仓库只保留占位图与文字回退。

推荐的产品边界仍是：

- 方形 App 图标可用原创占位；
- 完整字标如需官方版本，最好取得许可或只做本地替换；
- 公开演示视频默认用占位图，减少品牌误用风险。
