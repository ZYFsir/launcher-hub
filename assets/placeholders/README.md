# Placeholder icon pack

This directory is the **open-source, redistributable** icon set for the launcher template.

- `DESIGN.md` — original design briefs (concept and palette).
- `prompts/` — concrete Qwen-Image prompts used to generate the tiles.
- `generated/` — 1024×1024 PNG tiles generated by Qwen-Image-2.1-Turbo via sd.cpp.
- `generate.ps1` — reproducible local generation script.

- Reference sheet: community asset, **not redistributed**; kept in git-ignored `reference/`.
- Design briefs: CC BY 4.0.

## Important

These are **original placeholder marks**, not official brand assets.
Official marks are currently tracked in this repository by user decision; they are not MIT/CC0 and are documented in `THIRD-PARTY-NOTICES.md`.
Users/agents can still keep official variants local in `assets/official/`.

## Replacing an icon

1. Put the official asset in `assets/official/<app>/` (git-ignored).
2. Point the app manifest `icon.tile` / `icon.mark` to the local file.
3. Set `icon.source` to `official` and record `license` / `credit`.
4. Do not commit that local file.

See `../../schemas/app.schema.json`.
